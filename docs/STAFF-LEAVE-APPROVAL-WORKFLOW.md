# ข้อกำหนด workflow การอนุมัติและยกเลิกใบลา — ยืนยันจากเจ้าของระบบ

สถานะ: ข้อกำหนดธุรกิจที่เจ้าของระบบยืนยันแล้ว สำหรับสาขา `feat/staff-leave-management-design`; ยังไม่ใช่การ deploy Production.

## 1. สายการอนุมัติปกติ
1. บุคลากรส่งคำขอลา
2. รองผู้อำนวยการโรงเรียนพิจารณาเป็นลำดับแรก
3. เมื่อรองผู้อำนวยการพิจารณาเห็นชอบ จึงเสนอผู้อำนวยการโรงเรียนพิจารณาอนุมัติขั้นสุดท้าย
4. บันทึกผู้พิจารณา การตัดสินใจ เวลา และเหตุผลไว้ในประวัติที่ตรวจสอบย้อนหลังได้

## 2. กรณีผู้อำนวยการโรงเรียนไม่อยู่
- หากผู้อำนวยการโรงเรียนไม่อยู่ รองผู้อำนวยการโรงเรียนสามารถอนุมัติการลาได้โดยตรง โดยไม่ต้องรอขั้นอนุมัติสุดท้ายจากผู้อำนวยการ
- ระบบต้องเก็บเหตุผล/สถานะการใช้อำนาจแทน และผู้ดำเนินการจริงไว้ใน audit trail
- ก่อนเปิดใช้งานจริง ต้องให้ผู้รับผิดชอบยืนยันวิธีบันทึกว่า “ผู้อำนวยการไม่อยู่” (เช่น ผู้มีสิทธิ์ระบุสถานะ หรือเลือกเหตุผลในคำขอ) และตรวจความสอดคล้องกับระเบียบ/คำสั่งมอบอำนาจที่ใช้กับบุคลากรแต่ละประเภท

## 3. การยกเลิกคำขอลา
- ผู้ยื่นต้องดำเนินการยกเลิกก่อนวันเริ่มลาอย่างน้อย 1 วัน
- การตรวจสอบต้องทำฝั่ง server/database โดยใช้เขตเวลาของโรงเรียน (Asia/Bangkok) ไม่ใช่ตรวจเฉพาะหน้าเว็บ
- เมื่อไม่เป็นไปตามกำหนดเวลา ระบบต้องปฏิเสธการยกเลิกแบบอัตโนมัติและแสดงข้อความให้ติดต่อผู้มีอำนาจ/งานบุคคลเพื่อดำเนินการตามระเบียบที่ได้รับอนุมัติ ห้ามให้สิทธิ์ bypass โดยไม่บันทึกเหตุผลและผู้อนุมัติ
- เก็บประวัติการยกเลิก ผู้ดำเนินการ เวลา เหตุผล และสถานะก่อน/หลังไว้ตรวจสอบย้อนหลัง
- ต้องกำหนดความหมายให้ชัดว่า “ก่อนวันลา 1 วัน” หมายถึงก่อนวันเริ่มลาอย่างน้อยหนึ่งวันปฏิทินในเวลาโรงเรียนไทย; หากต้องการวันทำการแทน ต้องแก้ข้อกำหนดก่อนเขียน validation

## 4. Acceptance criteria
- เส้นทางปกติบังคับรองผู้อำนวยการพิจารณาก่อน แล้วจึงส่งผู้อำนวยการอนุมัติ
- เมื่อมีการบันทึกว่าผู้อำนวยการไม่อยู่ เส้นทางอนุมัติโดยตรงของรองผู้อำนวยการเปิดใช้ได้และมี audit record
- ผู้ยื่นไม่สามารถอนุมัติคำขอตนเอง
- การยกเลิกคำขอลาถูกปฏิเสธหากไม่ถึงกำหนดก่อนวันเริ่มลาอย่างน้อยหนึ่งวันปฏิทิน ตามเวลา Asia/Bangkok
- ทุกการตัดสินใจและการยกเลิกตรวจสอบย้อนหลังได้
- ข้อกำหนดนี้ยังไม่อนุญาตให้ deploy หรือเปลี่ยนฐานข้อมูล Production โดยอัตโนมัติ; ต้องมี migration ที่ทดสอบแล้วและการตรวจสอบระเบียบที่เกี่ยวข้องก่อนเปิดใช้งาน
