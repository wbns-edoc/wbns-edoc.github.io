# ข้อกำหนดผู้อนุมัติใบลา — ยืนยันจากเจ้าของระบบ

สถานะ: ข้อกำหนดที่เจ้าของระบบยืนยันแล้ว; ยังต้องตรวจเทียบระเบียบ/อำนาจตามประเภทบุคลากรก่อนเปิดใช้งานจริง  
สาขา: `feat/staff-leave-management-design`

## ข้อกำหนดที่ยืนยัน
เจ้าของระบบระบุว่า **ผู้อนุมัติใบลาคือผู้อำนวยการโรงเรียนและรองผู้อำนวยการโรงเรียน**.

## วิธีนำไปออกแบบ workflow
- ให้ workflow รองรับบทบาทผู้อนุมัติทั้ง `ผู้อำนวยการโรงเรียน` และ `รองผู้อำนวยการโรงเรียน`.
- แยก “ผู้อนุมัติที่มีสิทธิ์ตามบทบาท” ออกจาก “ผู้อนุมัติที่ได้รับมอบหมายในคำขอแต่ละรายการ”; ต้องกำหนดให้ชัดว่ารองผู้อำนวยการอนุมัติได้เองทุกกรณีหรือเฉพาะกรณีที่ได้รับมอบหมาย/รักษาราชการแทน.
- เก็บผู้ตัดสินใจจริง เวลา ผลการพิจารณา และเหตุผลในประวัติที่ตรวจสอบย้อนหลังได้.
- ป้องกันการอนุมัติคำขอตนเอง.
- ห้ามให้สิทธิ์อนุมัติจากการเป็น System Admin เพียงอย่างเดียว เว้นแต่เจ้าของระบบยืนยันเพิ่มอย่างชัดแจ้ง.
- ต้องตั้งค่าและทดสอบ authorization ฝั่งฐานข้อมูล/server ไม่ใช่ซ่อนหรือแสดงปุ่มในหน้าเว็บอย่างเดียว.

## จุดที่ยังต้องยืนยันก่อนเปิดใช้
คำยืนยันนี้บอกว่าใครเป็นผู้อนุมัติของโรงเรียน แต่ยังไม่ระบุว่า:
1. รองผู้อำนวยการอนุมัติแทนได้ทุกประเภทการลา หรือเฉพาะเมื่อได้รับมอบหมาย/รักษาราชการแทน.
2. ทุกคำขอต้องผ่านรองผู้อำนวยการก่อนผู้อำนวยการ หรือเป็นผู้มีอำนาจอนุมัติคนใดคนหนึ่งตามเงื่อนไข.
3. มีประเภทบุคลากรหรือประเภทการลาที่ต้องใช้สายอนุมัติแตกต่างกันหรือไม่.

ให้ตั้งสถานะ workflow/นโยบายที่ยังไม่ยืนยันเป็น pending configuration; ห้ามเดาสายอนุมัติหรือเผยแพร่ Production workflow จนกว่าจะตรวจระเบียบที่เกี่ยวข้องและให้ผู้รับผิดชอบอนุมัติ.
